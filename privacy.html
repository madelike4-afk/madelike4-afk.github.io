Privacy Policy

Effective November 6, 2026

This policy explains how Shorts Pipeline handles information. Shorts Pipeline is a private tool used only by the owner of the YouTube channel Made Like This.

Google and YouTube access

Shorts Pipeline uses YouTube API Services. It asks Google for one permission, youtube.upload, which lets it upload videos to the channel owner's own YouTube channel. It doesn't read, collect or store viewers' data, comments, subscriber lists, analytics or any other Google account data.

Your use of YouTube is covered by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

What is stored

The Google sign-in token is stored only on the channel owner's computer, in a file only that user account can read. It isn't sent to any server run by this tool, because the tool has none. The token is used only to upload videos to the owner's channel.

What is shared

No Google user data is sold or shared with anyone. Finished videos are uploaded to YouTube. Separately, frames from source clips and the script text are sent to AI providers (Anthropic, ElevenLabs and, as a backup voice, Microsoft Edge's text-to-speech service) to write the script and create the voiceover. Those requests don't include Google account data.

Website

These pages don't use cookies, analytics or sign-in forms. The hosting provider may keep standard server logs.

Removing access

The account owner can revoke this tool's access at any time from Google Account permissions. Deleting the token file removes the stored sign-in from the computer.

Changes

If this policy changes, the updated version will be posted here with a new effective date.
